📬 6. Kafka Event Streams (`notification-service`)

Topic Name Producer Consumer Payload Schema Action Triggered
user.created user-service search-service, notification-service { userId, firstName, lastName, email, headline, location } Indexes user in OpenSearch & sends Welcome email
connection.requested user-service notification-service { requesterId, receiverId } Sends connection request email notification
connection.accepted user-service feed-service, notification-service { requesterId, receiverId } Invalidates & refreshes Redis feed cache for friends
post.created post-service feed-service, search-service { postId, authorId, content, imageUrl, createdAt } Distributes post ID into followers' Redis timelines & indexes in OpenSearch
post.liked post-service notification-service { postId, userId, authorId } Sends like notification email to post author
